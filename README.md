# 🤖 AI Resume Analyzer

A beginner-friendly Python project that analyzes a resume against a job description and identifies matching and missing skills.

## 🚀 Features

- Resume skill extraction
- Job description skill extraction
- Skill matching
- Missing skill detection
- Resume-job match percentage
- Simple command-line interface

## 🛠️ Technologies

- Python
- Regular Expressions
- Set Operations
- CLI
